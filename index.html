Experience

Building and integrating across backend systems, web applications, and interface design. Here's where I've put those skills to work.

  1. PunchCentral (Web & Mobile App)

    April 2026

    PunchCentral is a cross-platform web and mobile gym and boxing management system featuring AI virtual training, fitness tracking, and matchmaking, built with Flutter, Dart, MySQL, and Mediapipe Pose. It supports administrative, membership, training, and event operations, with an interface designed to streamline gym management and enhance athlete training.

    • Flutter
    • Dart
    • MySQL
    • AI Training
    • Fitness Tracking

  2. Addictech (Web App)

    November 2025

    Addictech is a web-based point-of-sale and inventory management system for computer peripherals, built with PHP and MySQL. It supports sales and inventory operations, with an administrative interface designed to streamline system management.

    • PHP
    • MySQL
    • Point of Sale
    • Inventory Management

  3. VitalyTea! (Web App)

    February 2025

    VitalyTea is a web-based tea shop and printing-services storefront, built with HTML, CSS, JavaScript, PHP, and MySQL. It lets customers browse the menu, place delivery or pickup orders, and manage their accounts and order history.

    • HTML
    • CSS
    • JavaScript
    • PHP
    • MySQL

  4. Japan Drifts (Web App)

    July 2024

    Japan Drifts is a web platform celebrating Japanese car culture, featuring iconic JDM brands and vehicles alongside streetwear and automotive essentials. Built with HTML, CSS, and JavaScript, it brings together car discovery, curated content, and online shopping with cart and account features in an experience designed for enthusiasts of the cars and lifestyle.

    • HTML
    • CSS
    • JavaScript
    • JDM
    • E-commerce

  5. Aurena (Mobile App)

    August 2026

    Aurena is a personal productivity suite designed for efficient daily organization, featuring a comprehensive task ledger and rich-text notes alongside a scientific calculator and focus tools. Built with Flutter and Dart, it brings together deadline tracking, study-optimized timers with ambient audio, and a birthday manager in a highly themed experience designed for users who want a unified and aesthetic digital workspace.

    • Flutter
    • Dart
    • Productivity
    • Focus Tools
