# Prisma — Portfolio

A personal portfolio of Jaymard T. Licas, showcasing UI/UX design, web and mobile projects, video edits, technical skills, and certifications.

## Features

- Responsive layout with animated page introductions and section navigation
- Project carousel with filters for websites, mobile apps, and video edits
- Website and mobile project screenshot galleries
- Embedded Google Drive video previews
- Certifications section and contact links
- Smooth scrolling and reduced-motion support

## Run locally

This is a static website with no build step or package installation required.

1. Clone or download the repository.
2. Open `index.html` in a browser, or serve the project through a local web server.

or

1. Open browser
2. enter URL https://prismavl.github.io/Website-Portfolio/
